# 디자인 레퍼런스 분석: Lama Lama "Stacking Rows"

- 출처 영상: details.so/inspo/lamalama-580e90 (7.2초, 1920×1196)
- 실제 페이지: https://lamalama.com/services/branding/ (Amsterdam 브랜딩 에이전시)
- 분석 방법: 영상을 0.8초 간격으로 프레임 캡처 + 실제 사이트의 computed style과 CSS 변수 추출

## 1. 한 줄 요약

> 아이보리 배경 위에 **거대한 볼드 대문자 제목의 번호 행(01~04)**이 스크롤하면 **위로 올라가 계단처럼 겹쳐 쌓이는** 에디토리얼 레이아웃. 모노스페이스 소형 라벨이 대비를 주고, 마지막에 사진이 **ASCII 문자 디더 → 실사진**으로 드러난다.

## 5. 인터랙션 · 모션 상세

### ① Stacking Rows (핵심)
- 원본 클래스: `ll-block--stacking-cards` (JS + Lenis 스무스 스크롤)
- **CSS `position: sticky` 만으로 재현된다.** 행마다 멈추는 높이를 조금씩 내리면 된다.

```css
.row {
  position: sticky;
  top: calc(var(--header-h) + var(--i) * var(--peek)); /* i = 0,1,2,3 / peek = 60px */
  height: 360px;
  background: var(--off-white); /* 불투명해야 앞 행을 덮는다 */
}
```
- 모든 행이 **같은 부모** 안에 있어야 한다. 부모가 끝나면 스택 전체가 같이 빠진다 (영상 6.2s).
- 쌓인 행은 제목 윗부분만 보이도록 `peek`를 제목 높이의 절반 정도로 잡는다.

### ② 구분선 진행도
- 옅은 기본선(`::before`) 위에 진한 선(`::after`)을 `scaleX(progress)`로 키운다.
- progress = 행이 화면 아래에서 들어와 자기 sticky 위치에 닿을 때까지 0 → 1

```js
const p = clamp((innerHeight - rect.top) / (innerHeight - stickTop), 0, 1);
row.style.setProperty('--progress', p);
```

### ③ 텍스트 리빌
- 원본 클래스: `ll-text-reveal`, `js-text-reveal` (처음에는 `opacity-0`)
- 줄마다 `overflow: hidden` 마스크 안에서 `translateY(105%) → 0`, 약 0.9s, ease-out, 줄마다 70ms 스태거

### ④ 커서 칩
- 커서 오른쪽 위에 흰 모노 라벨. 행마다 문구가 다르다 ("FROM IDEA TO IDENTITY", "»")
- 좌표를 lerp(0.18)로 따라가 살짝 늦게 붙는다.

### ⑤ 헤더 태그라인 교체
- 섹션이 바뀌면 문구가 위로 빠지고 새 문구가 아래에서 올라온다. 로고 픽셀 모양도 같이 바뀐다.

### ⑥ ASCII → 사진
- 이미지가 처음에는 모노 문자(`@%#*+=-:.`)로 그린 명암 패턴이다. 화면에 들어오면 실사진으로 크로스페이드.
- 구현: 이미지를 문자 칸 크기로 줄여 canvas에 그리고, 픽셀 밝기에 맞춰 문자를 찍는다 → 사진 레이어의 opacity를 올린다.

### 모션 값 요약

| 항목 | 값 |
|---|---|
| 스크롤 | Lenis, lerp ≈ 0.1 |
| 텍스트 리빌 | 0.9s, `cubic-bezier(.22,1,.36,1)`, 스태거 70ms |
| 태그라인 교체 | 0.6s, `cubic-bezier(.65,0,.35,1)` |
| ASCII → 사진 | 사진 opacity 1.2s (0.5s 지연), ASCII opacity 0.8s (1.1s 지연) |
| 애니메이션 속성 | transform, opacity만 |

## 6. 디자인 원칙 (왜 좋아 보이나)

1. **극단적인 크기 대비**: 60~70px 볼드 제목과 10px 모노 라벨. 중간 크기가 거의 없다.
2. **무채색 + 여백**: 색이 없으니 타이포와 선이 주인공이 된다.
3. **선 하나로 구조를 만든다**: 박스나 카드 없이 1px 가로선만으로 행을 나눈다.
4. **스크롤 = 진행도**: 선이 차오르고 행이 쌓이면서, 읽은 만큼이 눈에 보인다.
5. **모노 라벨은 대괄호로**: `[ … ]` 표기가 기술적이고 편집된 느낌을 준다.

## 7. 내 PRD(열차 컨셉)에 적용하기

| Lama Lama 요소 | 내 사이트에 쓰는 방법 |
|---|---|
| 01~04 스태킹 행 | **4~7페이지 서비스 4개** (의류 쇼핑몰 / 전투력 측정기 / 돼이타베이스 / 포트폴리오). 재현 코드에 이미 넣음 |
| 구분선 진행도 | **노선이 차오르는 모션**으로 해석. 진한 선을 클로드 코랄로 바꾸면 곧 노선도 |
| 쌓인 행의 띠 | 지나온 역. "지나온 역이 위에 쌓인다"로 열차 메타포와 맞음 |
| 헤더 태그라인 교체 | **전광판 띠** "이번 역은 ○○입니다" (PRD 7.3) |
| 모노 대괄호 라벨 | 역 번호, 공사 중 배지: `[ 공사 중 ]`, `[ 04 / 08 ]` |
| 커서 칩 | 행마다 한 줄 소개나 기술 태그 |
| ASCII → 사진 | 1페이지 밈 이미지 공개, 또는 7페이지 포트폴리오 진입 |

- **컬러 충돌 주의**: 원본은 무채색이고, 내 PRD는 코랄 오렌지 노선이 주인공이다. 배경과 타이포는 원본을 따르고 **코랄은 선과 번호에만** 쓰면 둘 다 살릴 수 있다.
- 2페이지(구간 3개)와 3페이지(놈놈놈 3장)에도 같은 스태킹 행을 쓸 수 있다. 다만 전부 같은 모션이면 지루해지니 4~7페이지에만 쓰기를 추천한다.

## 8. Claude Design에 붙여넣을 프롬프트

```
에디토리얼 스타일의 "스태킹 행" 섹션을 만들어줘.

[스타일]
- 배경 #f9f4eb(아이보리), 텍스트 #010101. 무채색 위주. 포인트 컬러는 #D97757(코랄) 하나만, 구분선 진행도와 번호에만 사용
- 제목: 굵은 산세리프 700, 60px, 행간 0.8, 자간 -0.02em, 대문자 (한글은 Pretendard 800)
- 번호: 같은 폰트 70px
- 본문: 18px, 행간 1.2, 자간 -0.02em
- 라벨: 모노스페이스(Sometype Mono) 10px, 대문자, [ 대괄호 ]로 감쌈
- 좌우 여백 40px(모바일 16px), 12컬럼 그리드

[구조]
- 행 4개. 각 행 높이 360px, 12컬럼 기준 2/5/5 = 번호 | 제목 + 라벨 + 리스트 3개 | 설명(오른쪽)
- 행 사이는 박스 없이 1px 가로선만

[모션]
- 행은 position: sticky. top = 80px + index × 60px → 스크롤하면 위로 올라가 계단처럼 겹쳐 쌓인다
- 각 행 위 구분선: 옅은 선 위에 진한 선이 스크롤 진행도만큼 왼쪽부터 scaleX로 차오름
- 텍스트는 줄마다 마스크 안에서 아래→위로 등장 (0.9s, cubic-bezier(.22,1,.36,1), 70ms 스태거)
- 커서를 따라다니는 흰 모노 라벨 칩 (행마다 다른 문구)
- 상단 가운데 흰 알약 헤더(로고 · 모노 태그라인 · 햄버거). 섹션이 바뀌면 태그라인이 위로 넘어가며 교체
- 마지막 이미지는 ASCII 문자 패턴으로 먼저 보이고 실사진으로 크로스페이드
- prefers-reduced-motion이면 모든 모션 끄기

[콘텐츠]
01 의류 쇼핑몰 / [ 내 아이덴티티를 입히다 ] / 브랜드 기획 · 상품·주문 · 결제 보안
02 전투력 측정기 / [ 스카우터를 갖다 대면 ] / 대상 입력 · AI 전투력 산출 · 결과 카드 공유
03 돼이타베이스 / [ 내 것들을 한곳에 ] / 추가·검색·태그 · 표와 카드 보기 · AI에게 물어보기
04 포트폴리오 / [ 모든 게 모이는 곳 ] / 프로젝트 카드 · 상세 창 · 서비스 링크
```

> 참고용 분석이다. Lama Lama의 로고, 문구, 사진은 가져다 쓰지 않고 레이아웃과 모션 구조만 참고한다.
